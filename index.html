Installer le widget

  1. Installe l'app Scriptable (App Store, gratuite).
  2. Ouvre SurfLombok.js (version brute) et copie tout le code.
  3. Dans Scriptable, touche +, colle le code, nomme le script « SurfLombok ».
  4. Sur l'écran d'accueil, appui long → + → Scriptable → choisis une taille de widget.
  5. Appui long sur le widget → Modifier le widget → Script : SurfLombok.
