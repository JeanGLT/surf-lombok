Add the iPhone widget
  1. Install the free Scriptable app from the App Store.
  2. Open SurfLombok.js and copy all the code.
  3. In Scriptable, tap +, paste the code and name the script "Surf Lombok".
  4. On your home screen, long-press, tap +, choose Scriptable and pick a size.
  5. Long-press the widget, tap Edit Widget, set Script to "Surf Lombok" and When Interacting to "Open URL".
