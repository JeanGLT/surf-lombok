Add the iPhone widget

1
Install the free Scriptable app, then copy the widget script.
2
Create a new script in Scriptable, paste the code, tap the title to rename it "EasySurf", then tap Done.Open Scriptable
3
On your home screen, long-press, tap +, choose Scriptable and pick a size. Long-press the widget, tap Edit Widget, set Script to "EasySurf" and When Interacting to "Open URL".
The script updates itself, so you only install it once.
