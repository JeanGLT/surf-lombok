    Install the widget

    1. Install Scriptable from the App Store.
    2. Open the raw script SurfLombok.js, copy all the code.
    3. In Scriptable tap +, paste, name it SurfLombok, tap Done.
    4. Long-press the Home Screen → + → Scriptable → pick Small, Medium or Large → Add Widget.
    5. Long-press the widget → Edit Widget: Script = SurfLombok, When Interacting = Open URL, URL = https://jeanglt.github.io/surf-lombok/.
